Eenmalig je beheeraccount instellen

Gebruik je bestaande beheerwachtwoord om over te stappen. De oude ingang sluit pas nadat je authenticator is bevestigd. Activeer vanuit Nederland.

Koppel je authenticator

Scan deze QR-code met je authenticator-app. Je kunt de instelsleutel ook handmatig invoeren.

Inloggen

Op een vertrouwde browser in Nederland mag de code leeg blijven.

Geen toegang vanuit je reisland?

Met je gebruikersnaam, wachtwoord en een herstelcode krijg je tijdelijk alleen toegang tot de landeninstellingen. Voor het aanpassen daarvan heb je een tweede herstelcode nodig.

Bij verlies van je authenticator is hulp via het hostingbeheer nodig; bewaar je herstelcodes buiten dit apparaat.

Bewaar je herstelcodes

Elke code werkt één keer. Bewaar ze in je wachtwoordmanager of print ze. Je ziet deze codes hier maar één keer.
